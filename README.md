One line of text: funny, original, and tight.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
My smartwatch congratulated me for standing up, then reminded me to sit down and drink water — even my wrist is a micromanager.
```
